# Atmospheric Python Tools 🌤️

This repository contains a collection of Python scripts developed during my academic studies and laboratory exercises in Atmospheric Physics.

## Overview
These tools focus on processing atmospheric data, calculating meteorological variables, and visualizing the results (e.g., wind roses, statistical distributions).

## Libraries Used
* **Pandas, NumPy & SciPy:** Data manipulation, scientific computing, and advanced statistical processing
* **Matplotlib & Windrose:** Data visualization
* **MetPy:** Meteorological calculations

## My Approach & Workflow
As a physics student, my primary focus is on understanding atmospheric dynamics and the statistical logic behind the data. I treat Python as a practical tool to solve these scientific problems.

To work efficiently, I actively integrate AI assistants into my workflow. My process involves designing the logic and the physical constraints, utilizing AI to assist with code structuring and syntax, and then rigorously reviewing, modifying, and testing the scripts to ensure scientific accuracy. 

## Status & Continuous Learning
*This repository is a living project. It is actively updated with new scripts as I organize my academic and thesis work, reflecting my continuous journey to refine my programming skills and bridge atmospheric physics with data analysis.*
